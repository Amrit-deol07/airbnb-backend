
# Airbnb Backend

An Airbnb-inspired accommodation web application built using Node.js and Express.js.

## Features
- Homepage for browsing properties
- Add Home form
- Home submission success page
- Custom 404 error page
- Express routing
- Form data handling

## Technologies
- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## Installation

1. Clone this repository.
2. Run `npm install`.
3. Start the application using `npm start`.

## Local Development

Open `http://localhost:3000` in your browser.
